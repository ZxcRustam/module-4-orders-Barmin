# Информационная система «ЭлектроМир» — Каталог электроники

## Описание
Данный проект представляет собой локальное десктопное приложение для автоматизации работы сотрудников розничной компании **«ЭлектроМир»**. Система позволяет просматривать актуальный каталог доступной электроники, создавать и удалять заказы клиентов, оперативно обновлять информацию о продажах, а также автоматически корректировать складские остатки товаров в режиме реального времени.

## Используемые технологии
* **Язык программирования:** Python 3.x
* **Интерфейс:** Tkinter / ttk (встроенные компоненты GUI)
* **База данных:** SQLite 3 (локальное хранилище данных)
* **Работа с медиа:** Pillow (модуль PIL) для масштабирования графики товаров

## Назначение и основные функции
* **Интерактивный каталог:** Вывод витрины товаров с ценами, характеристиками и динамическим подсчетом доступного на складе количества.
* **Оформление заказов:** Позволяет добавлять выбранные позиции в чек, автоматически рассчитывать итоговую сумму заказа и списывать остатки со склада.
* **Управление заказами:** Просмотр всей истории продаж в виде таблицы `Treeview`, гибкое удаление ошибочных записей и корректировка дат.

## Роли пользователей
Приложение реализует разграничение прав доступа на основе ролей:
* **Клиент / Гость:** Доступен только базовый просмотр каталога без возможности оформления заказов и изменения истории.
* **Менеджер:** Имеет право просматривать витрину, создавать новые заказы и просматривать состав текущих заказов без возможности их редактирования.
* **Администратор:** Обладает полным доступом к системе, включая изменение даты заказа, удаление отдельных позиций чека или заказов целиком с автоматическим возвратом товаров на склад, а также переход в «Админ-панель».

## Порядок подготовки базы данных
Все данные хранятся локально в файле **`databases/db_variant_N.db`**. База данных включает следующие ключевые таблицы:
1. `Пользователь` — хранит учетные данные персонала (ФИО, логин, хэш пароля, роль).
2. `Товар` — каталог электроники (название, бренд, модель, цена, остаток на складе).
3. `Заказ` — общая информация о продажах (ID, дата оформления, ФИО клиента).
4. `Состав_заказа` — таблица связей со списком купленных товаров, их количеством и ценой фиксации.

**Данные для тестирования системы (логины):**
* Менеджер: `client1`, `manager1` (пароль: `admin1`)
* Администратор: `admin` (пароль: `admin1`)

## Порядок запуска приложения

1. Установите необходимые внешние зависимости (библиотеку Pillow):
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите главный модуль приложения из корневого каталога проекта:
   ```bash
   python main.py
   ```
